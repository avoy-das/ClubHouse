# Workspace Rules & Guidelines

## Emoji Prohibition & Icon Usage
- **No Emojis**: Do NOT use emojis anywhere in the project codebase, user interface (JSX/HTML), commit messages, or documentation files.
- **Lucide Icons**: Always use SVG icons from `lucide-react` for frontend UI components when visual icons or indicators are required.
- **Clean Documentation**: Use standard markdown headings, bold text, and clean formatting for all documentation without emoji decorations.
